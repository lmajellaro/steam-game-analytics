# Sample Database

This directory contains a snapshot of the Steam Game Analytics DuckDB database.

The sample database allows users to explore the Streamlit dashboards without running the Airflow ingestion pipeline or making API requests.

**File:** `steam_games_sample.duckdb`

The database is provided as a demonstration snapshot. Its contents reflect the data available when the snapshot was created and will not update automatically.

To use the sample database, follow the instructions in the main project README to configure Streamlit to use this file instead of the live database.
